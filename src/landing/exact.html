Create

How to use it: use the bulk actions in Printify Studio to remove backgrounds and create white-ink or black-ink versions for every design at once.

Mockup

Real photos. Real print area.

How to use it: open Mockups and drag a frame onto each photo to match Printify’s print area. Crop where a folded shirt would hide the design, then save the renders.

Describe

Write once. Apply to every design.

How to use it: open Listing details, write a title, description and up to 13 tags, set the price, then apply it to every design.

05

Check

Catch mistakes before Printify does.

How to use it: open Listing preview. The checklist shows exactly what Printify will receive. If something is missing, it tells you and links to the page that fixes it.

Questions

Will it publish by itself?

No. Send creates or updates a draft on Printify. Publishing is a separate click that only you make.

Do I need an Etsy API key?

No. ListBulkly works with Printify using your own Printify API key and shop ID. You publish from Printify to Etsy yourself. Etsy charges $0.20 per listing.

Do I need the extension?

No. The extension makes applying mockups one click, in Chrome or Edge. Without it, you can copy your selection and use a bookmarklet button instead.

Is my Printify login safe?

The extension never stores your keys or passwords. It works through your own signed-in Printify session in your own browser.

Is ListBulkly part of Printify or Etsy?

No. ListBulkly is independent and not affiliated with or endorsed by Printify or Etsy.
